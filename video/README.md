### 1. Accounts
Email + password signup/login · **Google Sign-In** (real OAuth + fallback) · persistent session (no random logout) · separate admin panel and user dashboard.

### 2. Deploy / Hosting
Upload **single file** `.py` / `.js` / `.html` **or a full ZIP** · auto project-type detect (Python bot / Node bot / HTML site) · **Deploy & Verify** with 6 checks · **Open Site** (real HTML/CSS/JS serving) · **Run Python** (real in-browser Python runtime, Pyodide — run the bot's commands live).

### 3. AI Auto-Fix (Ultra Pro)
Groq → OpenAI → local engine fallback · **Feature Lock Guard**: AI can never rename/remove a command, reply text, route or price string — only fixes the error · auto-generates `requirements.txt`, `.env` (with real token), `.env.example`, `Procfile`, `package.json`, `README.md` · logs + before/after diff.

### 4. 24/7 Bot Hosting
Bot worker runs until the plan expires · per-plan **and** per-user control from admin · auto restart + live status.

### 5. Site Tools (per website)
Daily Backup (real backup list) · Live Logs · Free SSL · Traffic Analytics · Env Variables editor · API Access token · Custom Domain · Priority Support.

### 6. Script Store
Admin uploads `.py` / `.js` / `.html` / `.zip` with name, description, **price**, icon, tags · access types: **Free / Paid / selected plans only** · users **search**, sort, **Buy → Download** · admin sees **who bought what**.
